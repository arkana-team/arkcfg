## Build

```sh
cargo build --release
# binary at target/release/arkcfg
```

arkanaOS builds this crate with `cargo build --locked --release`, so keep
`Cargo.lock` in sync with `Cargo.toml` when changing dependencies.

## Usage

```sh
arkcfg display list            # all connected outputs and their supported modes
arkcfg display current         # current resolution of each output
arkcfg display set 1920x1080   # set an output (default: primary) to a mode
arkcfg display set 1920x1080 --output HDMI-1
arkcfg sysinfo                 # fastfetch / neofetch, falling back to uname
arkcfg power restart           # asks for confirmation, then reboots
arkcfg power poweroff --no-confirm   # no prompt (for scripts)
```

`display set` only accepts a mode name that `display list` reports for the
target output; custom modes created with `xrandr --newmode` (e.g.
`1920x1080_60.00`) can be selected by their full name.

`display` commands require an X11 session with `xrandr` available. `power`
commands call `systemctl reboot|poweroff`, falling back to `reboot(8)` /
`poweroff(8)`; they must be run as root (e.g. via `sudo`).
